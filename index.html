Methodology

Context Classification → Signal Extraction → Priority Decision Engine. Each line is evaluated independently.

Decision Definitions

  • BLOCK → high-risk primitive or critical pattern.
  • WARN → suspicious signal requiring review.
  • ALLOW → no known high-risk signals detected.

Common questions
What should I paste?
Prompts, logs, API requests, URLs, snippets, error messages—anything technical you plan to reuse.
Does Validoon upload my data?
No. This build is designed to run locally in the browser.
Is ALLOW safe?
ALLOW means “no known high-risk signals detected.” It is not a guarantee.
